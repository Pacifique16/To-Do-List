# 📝 To Do List

A simple React To Do List app where you can add tasks, mark them as done, and delete them.

## Features

- Add new tasks
- Mark tasks as done / undo
- Delete tasks

## Project Structure

```
src/
├── main.jsx
├── App.jsx
├── index.css
└── components/
    ├── Button.jsx
    └── Todo.jsx
```

## Getting Started

### Prerequisites

- Node.js installed on your machine

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Pacifique16/To-Do-List.git
   ```

2. Navigate into the project folder
   ```bash
   cd To-Do-List
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173`
